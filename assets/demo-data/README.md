# 本机模拟档案

`newly-diagnosed.json` 和 `recurrent-treatment.json` 是两套完全虚构、只用于本机工作台页面/功能演示的夹具。内容包括合成的报告文本、病理/临床字段、指标趋势、治疗事件、营养/症状/私密记录、复诊问题和安排。不得用于临床决策、患者咨询、医疗训练或当作真实指南证据。

加载前，工作台要求用户明确选择一个**独立空白目录**。服务端只接受manifest中的固定ID；已有主体、记录或非零revision时拒绝加载，不覆盖或合并现有病历。要查看另一套档案，请另选新的空白目录。模拟资料与2026试验登记SQLite严格分开。

患者档案夹具沿用目前的`workspace-v1.json` schemaVersion=2；它们验证的是当前JSON数据加载和页面读模型，不代表患者SQLite schema已实现。
