### 定义

卵巢恶性肿瘤的病理类型很多，本台一期范围只覆盖**上皮性卵巢癌、输卵管癌、相应上皮性原发性腹膜癌**这三者。它们是同一诊疗框架下的**不同原发部位 / 疾病实体，不是「卵巢癌的三种类型」**——范围依据是卫健委《卵巢癌诊疗指南（2022年版）》第 1 页：输卵管癌及原发性腹膜癌可参照卵巢上皮性癌诊治原则（`docs/SPEC.md`、`docs/GAP-ANALYSIS.md`）。

三个维度必须分开，本项目最容易在这里写错：

- **组织学亚型**：高级别浆液性癌、子宫内膜样癌、透明细胞癌、黏液性癌等，是病理层面的分类（`docs/SPEC.md` 要求「卵巢组织学类型需单独保存」）。
- **分期**：FIGO 手术病理分期（版本未核实）。它描述病变范围，与亚型不是同一个轴。
- **分子状态**：BRCA1/2 胚系或体系突变、HRD 状态。这是第三层信息，**不是分期、也不能当亚型**；本台只存检测原文与日期，不据此写「能用什么药」。

另外两条边界：腹膜转移不等于原发性腹膜癌；腹水 / 腹膜种植不能自动判为原发性腹膜癌（`docs/GAP-ANALYSIS.md`）。

**来源**：国家卫生健康委 · 《卵巢癌诊疗指南（2022年版）》· 原件已取得（官方 PDF 36 页，2026-10-18 下载核对）· 第 1 页（范围说明）、第 11 页（病理分类和手术病理分期）｜ 本项目 `docs/SPEC.md`、`docs/GAP-ANALYSIS.md` · 一手项目文件

### 目前治疗全景概要

按治疗阶段分组，只列指南里出现过的**手段类别**，不含剂量、疗程与适用条件。

- **初治手术**：初次肿瘤细胞减灭术；部分情形先做新辅助化疗、再做间歇性肿瘤细胞减灭术——卫健委 2022 版把这两个话题并列提出（据 `docs/USER-RESEARCH.md` 记录）。
- **一线系统治疗**：以铂类为基础的化疗类别；之后是维持治疗这一类别（抗血管生成类、PARP 抑制剂类被列出，是否使用与用多久属医生判断）。
- **复发**：再次手术在特定情形下被讨论；系统治疗按「铂敏感 / 铂耐药」两种情境分别列出类别；放疗被列为**情境化选项**（部分复发情境），不是术后常规辅助路线。
- **少见组织学亚型与特殊原发部位**：按各自的病理框架处理，本台不把它们并入高级别浆液性癌的路径。
- **贯穿全程**：随访（卫健委 2022 版第 34 页起）／遗传咨询与家系信息（BRCA 检测结果属分子层，仅存原文）。

以上是文献与指南里列出的手段，按病期与线序排列，**不代表任何一项适合你**。选哪一个，这一句需要问你的医生。

```bash
npm install
npm run check
npm test
npm run pack:check
npm pack
```
