# 卵巢癌患者工作台需求简报

状态：用户已确认目标、三条综合治疗主轴、青绿色/社区Logo方向以及一期参考小胰宝、二期扩展家庭支持的分期原则，并授权继续设计。字段、交互和验收为设计提案；患者访谈与临床内容核验尚未完成。当前规格为 SPEC v0.9；HTML v3为待审核的交互原型，HVT新增场景尚未全部实现在原型中。

全局设置入口要求：各业务页右上角齿轮；设置患者资料目录、MinerU解析与社区共享凭据状态/用户替换、逐文件云端授权、临床数据包来源与版本。设置需独立于Desktop公共设置，并保护凭据与患者私密资料。

- **目标用户：** 上皮性卵巢癌、输卵管癌及对应上皮性原发性腹膜癌患者与照护者；原发部位/病理分开，腹膜转移不自动归为原发性腹膜癌，范围依据见GUIDELINE-SCOPE；覆盖初诊、治疗中、维持治疗、复发、安宁疗护与临终照护阶段，并延伸至患者去世后的家属哀伤支持。也考虑年轻患者的生育力与绝经相关问题。
- **照护框架：** 临床治疗、营养支持、心理支持是贯穿疾病全程的综合治疗三要素。安宁疗护与临终照护阶段仍需围绕症状舒适、营养与进食目标、患者及家属心理社会/灵性需要协同照护；工作台记录和支持沟通，不替代专业服务。
- **视觉方向：** 女性中心、温暖、有韧性的支持型体验；参考 National Ovarian Cancer Coalition（NOCC）的青绿色卵巢癌倡导语境，并使用小巢宝社区 Logo 作为社区身份标识。颜色和标识的具体使用规范见 [UI 设计方向](UI-DESIGN.md)，最终需经对比度及品牌授权核验。
- **场景：** 患者与家属跨医院、跨阶段管理分散的病理、手术、影像、实验室、分子检测、治疗计划、营养/症状及心理支持信息；需要为复诊、照护目标讨论、安宁疗护协作和家庭纪念/哀伤支持找到适当记录与资源。
- **已确认的优先主线：** 治疗期间的日常理解与照护＋患者/家属共同准备复诊。用同一资料和变化记录串联两者，减少重复填写；家属代办作为支持方式保留。
- **已确认的AI帮助：** 提供有来源、结合个人资料的解释与可讨论选项，帮助理解和准备决策；医疗处置由专业团队确定。详见 [AI-ASSISTANCE](AI-ASSISTANCE.md)。
- **核心任务：** 在本机资料目录导入或登记文件 → 核对提取候选项 → 形成可追溯的疾病与照护时间轴 → 记录临床治疗、营养支持、心理支持及症状/副作用 → 按阶段准备复诊、照护目标或家庭支持沟通摘要 → 交给 Desktop 原生 Agent 会话进一步整理并归档；患者去世后，由家属在明确授权与隐私边界下选择继续访问适用资料、纪念内容或哀伤支持资源。
- **分期边界：** 一期参照小胰宝现有功能广度，交付病程、日历、报告整理、指标、治疗历程、临床/营养/心理轻量记录、试验线索、回顾与导出；安宁疗护专属流程、家庭权限转换和去世后哀伤支持作为二期。二期不是一期上线的前置条件。
- **完成条件：** 确认的数据都能追溯至原始来源；未核对候选不进入当前档案，用户核对入档不等于医学验证；摘要能区分患者自述、报告原文、医生结论、家属记录、系统整理和待核实内容。生命末期偏好、照护目标及去世后的资料访问/分享由患者预先表达或家属依法依规确认，不由系统推断。
- **关键差异：** 以妇科肿瘤病理类型、FIGO分期、手术减灭/残余病灶、含铂治疗及铂敏感/耐药复发、BRCA/HRD等分子检测、维持治疗与家族遗传风险为主轴；不沿用胰腺癌特有的PEI等默认照护流程；血糖等通用指标仍可按实际需要启用。
- **待确认：** 中国目标人群/地域与指南适用范围、患者及丧亲家属访谈、安宁疗护/临终照护与哀伤支持的服务边界和转介资源、临床治疗/营养/心理支持记录的最小字段、症状量表与指标字典、是否纳入非上皮性卵巢肿瘤、家庭成员遗传信息及去世后资料访问边界、报告解析范围、原型与导航结构。

## 最新用户处境与待讨论设计

用户提供两条直接材料：新确诊时情绪崩溃、不知道下一步；病程中报告混杂治疗、无力整理核对/问诊和思考下一步。原文与限制见USER-RESEARCH，针对性场景提案见 [PATIENT-JOURNEYS](PATIENT-JOURNEYS.md)。前者需低负担的情绪承接与下一步导航，后者需把整合负担交给系统；交互和未核对草稿信任规则已形成DB01可修改设计基线（见LOW-BURDEN-WORKFLOW），未获逐项用户确认/验证，不因描述痛点就默认用户接受自动医学判断。

## 本轮补充的范围原则

病情整理、指标检测、独立一图秀、临床治疗与试验资料是一期核心模块，详情见 [CORE-MODULES](CORE-MODULES.md)。营养和心理各有独立入口及记录/回顾/分享闭环。支持/姑息照护可以与抗肿瘤治疗并行，安宁/临终及丧亲支持不设为自动顺序阶段。患者资料访问授权与家属自主获得支持资源分开。

## 明确限制

本产品提供资料整理、趋势展示、有来源的个人资料解释、可讨论选项与沟通准备，不筛查、不诊断、不预测复发、不计算个体治疗获益，可说明与已知资料有关的通用治疗/支持路径和需核实条件，不代替专业团队决定个体药物、手术、营养处方、心理治疗或试验入组；不判断预后或死亡时间，不替代安宁疗护、临终照护、心理治疗及专业哀伤辅导。治疗、营养和心理相关方案与指南内容必须标注来源、版本、地区、适用人群和核验日期，并由相应专业人员维护。去世后功能需尊重患者生前意愿、家属隐私与当地法律要求，不将家属哀伤当作疾病记录或自动化干预对象。
