# DSH 原生 Agent 右侧面板设计

状态：2026-10-18 用户确认 Agent 对话面板应放在右侧，工作台保持中央主工作区。此为设计合同修订；**当前已安装包尚未按右侧布局验收，不能声称已实现**。

## 交互合同

- 工作台保持中间主要空间；Agent 原生对话显示在右侧，不覆盖中间关键内容。
- 右上“AI 对话”按钮打开，使用 DSH Desktop 原生会话 UI；未点按前不自动创建会话。
- 首次打开复用当前工作台所有者明确绑定的会话；无会话时通过目标 RC 支持的创建 API 创建并绑定一次。并发点击只创建一个。权限/归属不明时失败关闭。
- 中间分隔边支持拖动，默认目标35%，可调范围25%–45%，保持左侧导航和中间工作区可用。键盘可调整并具有 splitter ARIA；具体断点需在交互原型确认。
- 右侧面板具名隐藏/关闭操作；收起后顶栏显示“打开 AI 对话”，可复用同一会话。关闭不是清除、删除或结束会话。
- 一键带入由用户明确选择资料并预览本次发送内容后触发。原生输入框已有草稿、附件或发送中时不得覆盖/追加/误发；允许复制回退。患者私密心理数据、未核候选和未选择的个人资料默认排除。
- 回复显示在 DSH 原生界面，不自动变成患者病历事实或工作台治疗建议。
- 窄窗口优先保持业务任务可操作，Agent 可收起为右缘抽屉；加载、权限、网络与版本错误均可重试，且不丢业务状态。

## 对原型的差距

`docs/prototype/workbench-v3.html` 是单页模拟原型，没有模拟 DSH 原生会话。之前开发记录把原生 Agent 放在左侧，现已由本决定改为右侧。应新增独立的宿主集成HTML状态稿，不把前端假聊天当作原生能力证明。
