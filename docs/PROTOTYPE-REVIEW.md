## 与乳腺癌 PinkyPal v0.3 的对照复核（2026-10-17）

参考原型：`/Users/qinxiaoqiang/Downloads/breast-cancer-workbench/prototypes/v0.3`（页面路由 `#timeline`）。该版本将多指标曲线、治疗时段、症状轨道、指标卡与过滤控件组成连续的一图秀；点位悬停可快速看日期/数值，治疗色带的区间表达清楚。小巢宝 v3 的设计选择不同：最多3项指标各用独立分面和纵轴，不把不同单位压进同一数值轴；核对候选与已接受记录分层；患者自述作为独立事件；加入卵巢癌的手术、化疗周期、维持/靶向、复发讨论及放疗被提及时的场景。乳腺癌的指标、治疗和症状字段不复用。本轮增加了可选症状感受轨道，覆盖腹胀/早饱、腹部或盆腔疼痛/压迫感、恶心/呕吐、排便变化、尿频/尿急、疲劳和手足麻木/刺痛。NCI患者资料列出腹部/盆腔痛或胀、进食易饱、泌尿急迫/频繁和胃肠道变化；NCI副作用资料列有疲劳、恶心和周围神经症状。症状并不特指卵巢癌，治疗副作用也因人而异，页面不作病因归属。来源：[NCI卵巢/输卵管/腹膜癌患者资料](https://www.cancer.gov/types/ovarian/patient/ovarian-epithelial-treatment-pdq)、[NCI治疗副作用](https://www.cancer.gov/about-cancer/treatment/side-effects)、[NCI周围神经症状](https://www.cancer.gov/about-cancer/treatment/side-effects/nerve-problems)。

本轮按对照发现并改进：
- 旧版把同一日期的事件竖线重复画进每个指标分面，事件密集处容易干扰趋势阅读；改为共用事件轨与全图日期标线。
- 手术、资料、实际治疗、治疗沟通、计划和患者自述现在有不同颜色/形状；计划用空心菱形与虚线提示。点选可打开原有事件详情；悬停/键盘聚焦可先读日期、事件和状态。
- 指标点与未核候选点增加原生悬停说明，包含日期、数值、来源/核对状态；原有点选查看出处和候选不连入已核趋势的规则保留。
- 加入短促的折线绘制、点位淡入和指标卡小趋势线显现；筛选、时间窗与选项变化后可感知图表刷新。动画沿原始折线逐点显示，不做平滑插值，并支持系统“减少动态效果”偏好。 指标卡翻面后的 sparkline 绘图区同步放大（加宽有效横向绘图范围并增加高度），外卡固定高度不变。
- 新增卵巢癌相关症状/身体感受轨道：可选记录一项、日期、1–3级主观影响、可选日常影响、患者本人/照护者代记；点位与共用日期范围对齐，不连成连续曲线，不补空白为0，不推断病因/病情/紧急程度。当前分级锚点是原型文案，需患者走查后确定。

本次复核仅为代码与交互规则检查。浏览器安全策略拒绝重新打开本地 `file://` 页面，因此本轮没有把改动宣称为已完成的视觉/交互走查；需要用户在打开 HTML 后审核事件标记、动画观感、症状轨道可读性与窄屏表现。
