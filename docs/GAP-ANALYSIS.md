# 卵巢癌工作台设计文档与原型差距审查 v0.3

日期：2026-10-17。审查依据：用户指出手术/靶向/放疗场景缺失、一图秀相对xyb过于简陋、多指标列表缺失、卡片展开方向错误；参照 `breast-cancer-workbench/docs/GAP-ANALYSIS.md` 的“可复现缺口→规格根因→修订/验收”结构。xyb-workbench只读对比。

## 0. 范围先纠正：三者是什么、原发腹膜癌是否纳入

一期内容范围为**上皮性卵巢癌、输卵管癌、相应原发性腹膜癌**。三者是相关诊疗框架中的不同原发部位/疾病实体，不是“卵巢癌的三种类型”。卵巢组织学类型需单独保存；“腹水/腹膜种植/腹膜转移”不能自动判为原发性腹膜癌。中国卫健委2022版指南第1页明确输卵管癌和原发腹膜癌可参照卵巢上皮性癌诊治原则；这只能支持范围框架，不代表2022版仍是最新治疗依据。CSCO官方资料确认2025指南已发布，但本轮没有全文逐条核验。

具体逻辑与验收见 [GUIDELINE-SCOPE](GUIDELINE-SCOPE.md) / [AC22](ACCEPTANCE.md)。

## 3. 医学边界与场景选择原则

- 手术场景聚焦患者如何理解团队提到的初次减瘤手术、先系统治疗后间歇手术、手术记录/病理/残余病灶原文及需要问清的事；应用不评价可切除性或替医生选路线。
- 靶向/维持场景让患者能找到已有BRCA/HRD/既往治疗资料、理解医生提出的理由、询问目标/时长/监测/不良反应；各药物适应证不跨指南地区合并，也不据一条分子结果自动推处方。
- 放疗按指南语境作为特殊/少数情境的问答入口，不放成治疗主时间线的必经节点，不暗示是术后常规辅助。依据与年代见GUIDELINE-SCOPE；内容上线前逐条核验当时中国指南与专业意见。
- 复发场景不能自动套“铂敏感/耐药”单一时间阈值标签；整理既往实际治疗、比较影像和医生提出的选项。
- 多指标清单是“已存在/已录入的报告分类”，不是系统建议用户全部检查。不同单位、方法、日期精度分组；CA125不单独判复发；示例无参考区间。
- 临床/营养/心理主轴仍共享患者自选资料和复诊问题。记录症状与时间不自动建立药物因果，私密心理内容默认不进入一图秀/导出。

## 6. 结论分级

- **已复现：** v1的单指标固定图、无图表控制、无事件轨、多指标占位和纵向展开缺陷。依据是HTML函数/结构及与xyb CSS实现的只读对比。
- **已写入规格/原型：** OVC场景、范围与指南限制、分面多指标、日期缩放、治疗节点、3D独立卡片及新的AC25–AC27。代码语法/模拟DOM验证后另记录；当前未声明通过真实浏览器视觉验收。
- **仍未验证：** 患者是否希望同时看3项、是否理解缩放和分面、七项虚构指标是否形成误导、手机上多轨可读性、卡片动效可用性、临床话题词汇是否贴近患者表达。需患者/照护者走查及临床内容审阅。

本审查是对设计完整性与交互实现的纠偏，不代替正式患者访谈、指南全文解读或医生确定个体方案。

## 8. v3 HTML 与当前实现 parity 复核（2026-10-18）

用户指出一图秀、指标分析、临床病理和检索与v3不够一致。逐项对照结果见 [V3-PARITY-REVIEW](V3-PARITY-REVIEW.md)。结论为：现有业务域覆盖丰富，但不能以“功能存在”证明与v3交互1:1；一图秀连续主视觉/缩放动画与指标全量卡片编排、临床九个二级任务入口仍有架构与表现差距。临床检索从v3单条虚构demo增强为2026本机多登记源快照查询，需按来源元数据/筛选/详情/收藏/错误态验收，不应退回伪真实demo。

**Agent布局纠正：** 原SPEC和PROTOTYPE-REVIEW此前写为左侧原生会话，现根据用户要求修订为右侧面板、工作台居中主区；详见 [AGENT-PANE-DESIGN](AGENT-PANE-DESIGN.md)。提示词已同步到 `prompts/DSH-AGENT-PANE-INTEGRATION.md` 与 `xyb-workbench-starter`。当前生产包未按新布局验收，作为后续UI变更跟踪。
