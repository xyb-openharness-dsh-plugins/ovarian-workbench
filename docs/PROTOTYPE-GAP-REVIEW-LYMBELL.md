# 小巢宝一图秀对照 LymBell 原型与重构记录

参考页面： [小铃铛 LymBell · 淋巴瘤工作台 v0.1.0](http://127.0.0.1:53750/static-html/6eccd661ecff63f1/index.html#timeline)（本机原型；数据为淋巴瘤演示资料，不复用其临床数据）。审查对象：小巢宝卵巢癌工作台 `docs/prototype/workbench-v3.html（v3.1原型精修）` 与 `lib/client.js` 当前实现。

## 对照后发现的差距

| 维度 | LymBell 原型 | 重构前小巢宝 | 改造要求 |
| --- | --- | --- | --- |
| 病情一图秀布局 | 左侧固定筛选栏，右侧主图；时间、指标、显示选项在一处 | 选择指标和时间显示分成两张大卡，图被挤到下方 | 改为侧栏控制 + 主图的工作区，窄屏时控制栏回到主图上方 |
| 多指标对照 | 单图最多4条带图例的曲线，所有曲线共用日期轴；每条按自身范围归一化 | 每个指标单独生成一张图，指标间需要滚动比较 | 一个共同日期轴展示最多4组指标，颜色、图例、范围及末点值一一对应；明确提示不同指标和单位不可比 |
| 治疗/检查节点 | 化疗区间、治疗节点和评估节点使用独立轨道，不遮住指标曲线 | 治疗事件另放一张大卡，和指标图区分离 | 治疗/检查事件落到曲线上方的独立日期轨，并提供可点击事件列表 |
| 时间控制 | 近3/6/12个月与全期快捷筛选，缩放右端锚定最新记录 | 下拉选择范围和滑杆分散在展示卡里 | 侧栏提供快捷时间范围、缩放、治疗/检查显隐和待核候选独立预览 |
| 变化识别 | 曲线端点标出数值；颜色图例显示指标单位和全期范围；点位可固定来源详情 | 单色独立小图，缺少多序列的末点标签与总览图例 | 彩色平滑多序列、末点值标签、含单位/范围的图例；点位仍进入来源与核对状态详情 |
| 动态反馈 | 曲线以描边动画出现，点位依次弹出；治疗标记淡入 | 之前实现依赖静态展示，数据为空时没有任何曲线；也没有清晰重播入口 | 数据到达后自动绘制；加“重播趋势动画”；尊重系统减少动态效果设置 |
| 指标卡 | 固定高度的真实 Y 轴翻面，正面显示最近值，背面显示最近5次小趋势，卡片各自控制 | 有翻面卡，但类别/使用密度/曲线无法与共同日期轴呼应 | 保留 Y 轴翻面和独立状态；按卵巢癌标志物、血常规、肝肾/营养等类别分组，正面摘要、背面趋势 |
| 示范资料加载 | 侧栏可切换独立演示档案 | 模拟档案入口原来只在首次建档页；空白建档后消失，还要重新选目录 | 首页直接载入两套卵巢癌虚构档案；当前目录为空白壳时直写；空目录没配置时仅首次选择保存目录；已有病历拒绝写入；未编辑的模拟档案可直接切换 |
| Agent 控件 | 工作区职责清楚 | 顶栏和Agent面板重复显示宽度调节控件 | 去掉两处重复宽度控件组；保留可拖动分隔线、键盘调宽、面板显隐和面板内隐藏按钮 |

## v3.1 原型精修结果（按脚手架 19-PROTOTYPE-CRAFT）

先更新原型，暂不把这一轮新增原型交互同步到应用代码；待用户审核后再开发。

1. **共图与轴语义**：病程图改为单 SVG 最多4条卵巢癌相关指标曲线共享日期 X 轴，颜色、图例、单位、全期范围、记录次数及末次值标签一致映射。每条曲线依自身全部历史记录范围归一化；图内常驻不可比较声明。
2. **事件泳道**：手术、病理、化疗/治疗、维持靶向沟通、计划及患者自述/照护事件集中在图上缘的独立轨道，轨道引线止于曲线区上缘，不再穿过数据区；完整事件清单仍可点击查看。
3. **点位两层查看**：指针靠近点位时显示最近数据点提示；点击后在图下固定来源卡，呈现日期、值、单位、核对状态、来源入口和收起动作。键盘焦点、title 与 aria-label 保留。
4. **动态图**：平滑曲线按 pathLength=1 在统一0.85秒内绘制，点位错峰弹入，事件独立淡入；提供“重播趋势动画”。系统减少动态效果时曲线必须立即呈现完整终态，卡片保持可读的静态正反面。
5. **时间/选择**：近3/6/12月与全部记录改为可感知的 chips；缩放右端锚定全局最新日期；最多4项，超过上限回弹并解释；候选仍单独预览，永不并入正式趋势。
6. **卡片与患者场景**：指标卡固定194px高、Y轴真实翻面、每张独立控制；前面显示最新结果/日期，后面显示最近五次动态图、日期跨度与来源核对提示。现有手术评估/术后病理、化疗周期、维持靶向、复发讨论、放疗被提及时等卵巢癌患者话题入口继续保留，并在病程共图中呈现对应手术、周期、沟通、计划节点。
7. **视觉与无障碍工艺**：保留青绿色品牌体系，不照搬乳腺癌粉色值；补齐44px按钮/时间筛选触达高度、可见键盘焦点、数值等宽、冷色品牌与暖色主行动色区分、移动端控制栏折行和仅图内横向滚动。

## 对 19-PROTOTYPE-CRAFT 的差距评估

文档把令牌骨架、固定布局结构、语义组件、动效参数、鼠标/键盘交互和复刻验收写成可执行规则；色值按癌种替换。此结构适用于小巢宝。它与 `16-ONE-CHART-SPEC` 是互补关系：19号管工艺和界面细节，16号管趋势、数据域和医学表达。原型精修已吸收关键交互条目，但还需在用户评审后补完整五档宽度/横向溢出视觉走查、图表可读性患者走查以及SVG最近点与焦点状态验证。

值得区分的内容：乳腺癌的浅纸色、粉色品牌、私密卡配色等不能原样套用；业务名称、行动色可调整；固定高度独立翻面、同源时间轴、候选隔离、事件不遮曲线、reduced-motion 完整终态、帮助型空态、键盘/触屏支持属于通用工艺合同。

## 应用实现现状

应用包 v0.1.49 已安装到 DSH Desktop App 自己的 Harness profile，并且包含共用日期轴、最多4条指标曲线、分离事件轨、动画重播及直载示例档案。v3.1 原型本轮新增的最近点提示、点击固定来源卡和更严格的泳道/动效参数尚未同步到应用实现；按本轮优先级，先请用户审阅原型后再进入应用重构。当前运行中的 DSH Desktop 进程未重启，重新启动才会载入已安装的 v0.1.49。

## 验收重点

- 原型 v3.1 使用虚构资料并明确标记；实际应用示例入口直接加载且已有事实与个人命名工作区受保护。
- 新确诊和复发两个夹具分别验证：至少3种独立指标系列、多个日期点、事件轨、图例、来源详情、所有指标卡和临床历程。
- `prefers-reduced-motion` 用户不运行曲线/点位/事件动画，但图表内容完整可读。
- 验收依据包含 `npm test`：客户端 DOM 有且仅有一个共享 SVG、至少两条指标线、治疗节点和图例；点位与曲线动画可重播；后端允许未编辑模拟档案切换，同时拒绝真实记录/已编辑演示覆盖。
