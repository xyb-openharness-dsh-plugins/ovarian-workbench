# 文档审查与修订记录（2026-10-17）

审查对象：上一轮SPEC v0.2及BRIEF、UI、调研、分期、功能审查和任务。审查依据：用户明确要求、多核心场景、本机xyb-workbench README 0.1.27与客户端、社区starter合同和本轮权威来源复核。旧文档保留在 `_archived/review-2026-10-17-v0.2/`。

**结论：上一版可以说明愿景，但还不能直接指导四个重要模块的完整实现。** 主要问题是功能描述过粗、页面结构不一致、数据来源和临床验证混淆，以及分期/验收条件有矛盾。本轮修复规格和追踪关系；不代表业务实现或专业审核已通过。

## 本轮外部核实依据

- [NCI支持/姑息照护](https://www.cancer.gov/about-cancer/advanced-cancer/care-choices/palliative-care-fact-sheet)：可与抗肿瘤治疗并行，不能与hospice/临终自动等同。
- [NCI营养](https://www.cancer.gov/about-cancer/treatment/side-effects/appetite-loss/nutrition-pdq)、[腹水](https://www.cancer.gov/about-cancer/treatment/side-effects/ascites)：进食困难和液体潴留等语境影响记录解读，不能把体重变化直接解释为营养变化。
- [NCI哀伤](https://www.cancer.gov/about-cancer/advanced-cancer/caregivers/planning/bereavement-pdq)：哀伤也可发生在死亡之前，家属支持不宜设为死亡后才解锁。
- [中国单中心遗传检测研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC13328409/)：研究分母核实。其他未开展的临床内容和当前指南推荐不在本轮已验证范围。
