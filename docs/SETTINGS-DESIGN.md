# 小巢宝工作台设置设计 v0.1

状态：一期设置页提案；需与HTML v3共同审核，尚无生产配置或服务接通。参考 `xyb-workbench/docs/design/prototype-v2.html` 的分区设置弹层及当前工作台凭据/目录行为；只借鉴配置任务和状态表达，不复制胰腺癌内容。

## 目的与入口

用户需要在开始整理报告前，确认个人资料存放在哪里、选择扫描件处理方式、知道数据何时离开本机。设置服务于患者与照护者管理工作区，不以技术参数为首页主任务。

- 全部工作台页面的顶部右侧保留齿轮按钮；无文字时必须有可读名称“设置”，键盘焦点、触控区域和提示文本可见。
- 点击齿轮打开“工作台设置”大弹层/窄屏全屏页；标题、关闭入口固定，内容区单独滚动，底部取消/保存动作固定；关闭/取消不提交未保存设置。
- 齿轮属于小巢宝业务工作区入口，不遮挡或替代 Desktop 的公共导航、全局设置、模式切换和 Agent 会话。
- 设置入口在未配置资料目录/解析服务故障时保持可达；顶栏目录状态有文字且链接到本页对应分区，不只依赖颜色或齿轮角标。

## 页面分区与状态

### 1. 患者资料目录

显示当前工作区真实可读写的本机资料目录及状态：未选择、检查中、已连接、不可用。路径状态来自后端目录初始化/访问结果，不能仅因设置里有路径字符串就显示已连接。

- “选择/更换患者资料目录”调用宿主原生目录选择器；取消不改配置。
- 确认新目录前，说明现有记录仍留在旧目录，不会自动搬迁、合并或删除；如提供迁移，必须是独立的预览、备份、显式确认、逐项校验和失败恢复流程。
- 选择成功后再次检查读写并显示实际路径；失败保留旧值及恢复入口。活动任务在切换时提示未保存内容如何处理。
- 患者病历、报告、私密心理记录、导出产物与工作台配置分开存储。配置目录不成为任意文件读取权限。

### 2. 报告解析与 MinerU

默认显示“社区 MinerU API 已配置（共享服务）”，对应小胰宝社区发布的共享凭据来源；界面不读取、展示或回显密钥明文。实际实现复用受维护的社区凭据提供器/发布配置，不把凭据复制进患者项目的SPEC、HTML、提示词、截图、日志或普通示例。社区凭据不可用时显示“未配置/不可用”，不能伪装已连接。

- 同时提供“仅本机解析”与“MinerU 云端解析”两种模式；本地模式范围、可处理格式及不支持类型说明清楚。
- 支持用户自备 MinerU Token 替换共享凭据：密码输入框仅在正式实现中收集，保存后只回显“已配置/来源”，不得显示已有明文；允许清除自备项并恢复共享默认来源。HTML原型不接受真实密钥，仅提供演示状态切换。
- 在任何文件出站前明确告知本次选中的文件、目的服务和处理范围，并由用户主动确认；设置页保存同意不等于每份敏感文件自动上传。未同意或切回本地时不得调用远端。
- 患者档案、遗传结果、治疗记录、问题、收藏和心理记录不作为凭据或解析配置的一部分发送。上传只包含当前明确选择的原件及解析所需数据；解析结果作为待核对候选，回源后才由用户接受。
- 说明共享额度/可用性可能变化、Token失效/限流/超时处理、可选的本地降级和重试；不得保证公益服务持续可用，不因密钥失败丢失本地原件。
- 配置保存到工作台私有配置/系统安全存储，权限受限、原子更新；不写入患者资料目录、导出、诊断日志或前端API响应。报错必须对凭据做脱敏。

实现状态（2026-10-22）：设置页读取小胰宝已安装包的共享 MinerU 凭据提供器，不将凭据复制进卵巢癌包；个人 Token 经 DSH Host credential store 保存，状态接口只返回来源/可用性。转录按钮每次要求对当前原件单独确认；转录 Markdown 存在所选资料目录的 `extractions/` 下，并在文档记录中注明引擎（`mineru-api-pipeline` / `mineru-api-vlm`）、页数、时间和同意时间。TXT 可切为本机读取。当前不是后台队列，也不会自动将转录文本解析成临床字段候选；需要患者逐项对照并手工录入。

**解析通道已换（2026-10-22）**：不再调用 `mineru-open-api` CLI，改为直连 MinerU **HTTP API v4** 四步（申请上传链接 → PUT 上传 → 轮询批次 → 下载 zip 取 `full.md`）。理由是 Desktop 从 Finder 启动时 PATH 里没有那个二进制，市场分发的用户机器更没有——原来设置页那句「未找到 MinerU CLI；云端解析暂不可用」会变成默认状态。现在状态接口返回 `transport: 'http-api-v4'` 与 `model`，不再有 `cliAvailable`。

**凭据优先级**：用户在设置里保存的 Token（Host credential store）> 本机 `.secrets/mineru.json`（唯一本地密钥文件，600、已在 .gitignore）> 环境变量 `MINERU_TOKEN`（仅兜底）> 随包社区凭据。文件优先、env 其次：一条遗留的过期 env 不该长期盖住界面里新存的 Token。

**Flash 不再做**：2026-10-22 用户定「flash 不用了」。认证失败时只报错并给申请链接（`https://mineru.net/apiManage/token`），不假装降级成功，也没有免 token 的旁路。

### 3. 临床参考与数据包目录

患者资料目录与临床参考内容是不同的数据域、权限和生命周期。设置页单独显示内置/导入的指南、指标字典、药物术语和试验登记快照：来源、地区、版本/发布日期、覆盖范围、最后校验时间、当前状态、是否只读。未下载/过期/未审核/联网失败不可显示为“无结果”或当前指南。

- 有单独参考数据包目录时只允许受验证的包管理器读写；不让患者资料移动或覆盖临床内容。
- 卵巢癌内容需区分中国指南、美国参考资料与商业/社区数据；来源地区不可省略。药物适用、方案、放疗语境等上线前需要临床审核和明确维护责任人。
- v0.1.16内置“指南与患者资料来源”只读metadata目录：显示来源发布方、地区、版本/更新日期、核验状态、适用边界和官方链接。它不包含指南全文或个体推荐，不冒充指南管理器。
- CSCO 2025官方发布元数据已确认，但推荐正文未逐项核验；卫健委2022版用于范围说明，明确其为较早版本；NCI内容标美国来源，不能直接作为中国适应证/可及性结论。
- 临床研究登记继续独立显示2026快照与覆盖限制；登记不是指南、疗效等级、实时招募或入组判断。

### 4. 显示与工作台信息

显示版本、资料目录状态、解析凭据来源状态、临床数据包状态、隐私说明与帮助入口。大字可在本页或顶栏切换，偏好明确是本机临时或持久设置。Desktop 管理模型、模式、工具权限与快捷键；小巢宝设置不重复托管这些平台设置。

## 保存、取消、错误与验证

- 页面打开时读取当前值；编辑使用独立草稿；保存按钮写入后端成功再更新状态。取消、ESC、点关闭按设计提示未保存更改，用户选择丢弃/返回编辑。
- 目录选择取消、目录权限失效、保存失败、密钥被拒、云端未同意、共享服务不可达、数据包版本过期都必须有具体说明及可恢复操作。
- 保存失败保留草稿但不显示已保存；重新加载以真实后端状态为准。并发/目录切换期间旧请求不能覆盖新配置。
- 每个分区只显示必要信息，低频原理和限制默认折叠，摘要状态来自同一配置源；不因关闭帮助说明而隐藏阻断错误。
- 空目录、长路径、窄窗/大字、读屏标签、键盘焦点回归、弹层滚动与按钮触达面积纳入原型走查。

## 一期交付范围与暂缓

一期HTML与业务设计范围：全局齿轮入口、目录状态/选择、更换前保护提示、解析模式、共享凭据默认状态/用户替换状态、逐文件云端授权提示、临床数据源版本/状态、保存/取消/失败状态。真实凭据调用、文件系统目录选择、迁移/备份、在线数据包更新和API连通不由静态HTML原型宣称已实现。
