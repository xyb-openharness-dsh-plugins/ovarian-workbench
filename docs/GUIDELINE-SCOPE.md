# 癌种范围与指南对应 v0.2

核对日期：2026-10-17。结论用于确定本工作台资料模型与内容边界，不是诊断或个体治疗建议。

## 1. 三个原发部位与一个常见管理框架

一期拟支持**上皮性卵巢癌、输卵管癌及相应上皮性原发性腹膜癌**的患者资料。三者是不同原发部位，不是“卵巢癌的三种病理类型”。原发性腹膜癌纳入参考管理框架，不意味着其原发部位写成卵巢。卵巢癌本身另有上皮性、生殖细胞、性索间质等病理类别，不能混为同一套治疗知识。

“原发性腹膜癌”与“其他癌腹膜转移”不同；看到腹水、腹膜病灶或种植不能由系统判定原发性腹膜癌。腹膜其他肿瘤、其他部位癌的腹膜转移、卵巢转移瘤不自动适用本内容框架。原发部位和组织学未定时保存报告原文/未知，不自动归类；提供通用整理和沟通帮助仍可继续。

## 3. 需要落实到字段与内容路由的区别

- `primary_site`：ovary / fallopian_tube / peritoneum / unknown / other；来源和确认状态必留，不能从导航名或病灶位置推断。
- `histology`：原文、归一代码及字典版本；分级另存。高级别/低级别浆液性、透明细胞、黏液性等不能仅因同一原发部位得到相同药物解释。
- `disease_extent`：报告中原发/转移描述、分期原文、分期体系及版本与时间；与primary_site分开，不自动反推原发。
- `content_scope`：独立内容包的地区、指南/版本/章节、支持的部位/组织学/阶段与审核状态。未知字段返回“适用条件待明确”，不把缺失当符合。
- `guideline_scope_group`：epithelial_ovarian_related只描述已经核验到的适用框架，不覆盖或改写诊断原文；具体推荐须另连指南版本/章节和内容适用条件，非上皮性或不明病理的资料仍可保存。

## 4. 范围验收（文档/后续实现）

1. 报告原文为原发腹膜癌时，显示原发部位腹膜而非自动写卵巢；附相关指南框架说明。
2. 只写“腹膜转移”不能自动切到原发腹膜癌，部位未知可保持未知。
3. 卵巢生殖细胞/性索间质/交界性肿瘤和转移瘤不调用上皮性特定治疗内容；仍提供归档/沟通帮助。
4. 内容引用具体版本/章节；旧版依据不能标最新版，国际适应证不伪装为中国当前标准；2025版CSCO正文尚未逐条核验前不展示药物推荐等级/具体适应证。
5. 内容里“考虑/可讨论”必须保留其患者条件与上下文；用药与手术选择不得根据单一分子/影像字段自动路由。

## 5. 内置来源目录（v0.1.16）

`assets/reference-data/ovarian-cancer-guidance/manifest.json` 与 `sources.json` 是**来源元数据目录**，不含指南全文和可直接用于治疗推荐的摘录。设置页从只读包动态显示发布方、地区、版本日期、核验状态、适用边界及原始链接。CSCO 2025 仅确认发布元数据，推荐内容尚未逐条核对；卫健委2022版仅已核实范围声明；NCI为美国证据摘要/患者资料。患者可打开原始来源，与医生讨论。ClinicalTrials.gov/ChinaDrugTrials/ChiCTR登记包仍是独立数据域，不互相替代。

发布前复核：来源链接与版本；CSCO正文可用性和章节级核对；每项患者解释的原文/章节、地区及适用人群；临床审核者与复核日期。未经临床审核不呈现方案等级、药物适应证或“最新指南推荐”。
