# 对照 xyb-workbench 的功能审查 v0.1

状态：范围决策草案。对照来源为本机 `xyb-workbench/README.md` 当前功能说明；不是复制既有实现或患者数据。

| 小胰宝功能 | 决策 | 卵巢癌工作台一期的处理 | 主要审查点/不照搬项 |
| --- | --- | --- | --- |
| 病程一图秀/时间轴 | 保留并重做 | 诊断、组织学/分期、手术、治疗周期、分子检测、影像/实验室、症状及支持照护按时间串联 | 不能把胰腺癌指标或事件字段直接映射过来；所有数据可回源，未知不补全 |
| 首页日历/本机待办 | 保留 | 复诊、检查、治疗、营养/心理支持等用户自建安排 | 不自动生成临床日程/用药提醒；一期可支持未来14日视图，周期治疗重复事项由用户管理 |
| 病情整理/报告导入 | 保留 | 本地PDF/图片及常见文本导入；可追溯到页码/原文的解析候选，逐项确认后写入 | 不使用演示数据替代真实资料；远程解析默认关闭且逐次告知范围，禁止复用公开/内置服务密钥 |
| 文档解析后台任务 | 保留能力，重审供应方 | 首期优先本地文本读取；可插拔解析服务作为显式可选配置 | 不照搬随包公益 Token；云服务、传输地域、隐私告知和数据删除均需产品决策及合法审查 |
| 指标趋势 | 保留并领域重建 | CA125及患者实际有记录的HE4/化验指标，允许按报告新增指标 | 不预置胰腺/糖代谢指标分类；跨机构参考范围并列，不做诊断/复发阈值判断 |
| 临床试验 | 保留为查找线索 | 可使用经许可、有版本与更新时间的本机卵巢/输卵管/腹膜癌试验快照；详情、收藏、导出/询问 | 不复用胰腺癌试验库；若数据授权/更新质量不达标，一期先做静态来源入口或延期，不宣称实时；不计算入组资格 |
| 营养、心理支持和全程管理 | 保留并扩展为三条并列支持主轴 | 轻量记录治疗沟通、营养/进食体验、心理/情绪自述和希望讨论事项 | 不提供营养处方、心理诊断/疗法或自动分诊；记录负担应可配置、可跳过 |
| 收藏与回顾 | 保留 | 收藏材料/试验线索/Agent任务/摘要并能返回上下文 | 收藏对象含来源和日期；不让Agent生成内容伪装成临床事实 |
| 报告导出 | 保留 | 复诊摘要及用户选择的资料导出；HTML、Markdown作为首选可验证格式，PDF/DOCX/JPEG按真实效果逐项验收 | 默认隐去遗传/家属敏感信息；导出前预览内容和目的地，不以扩展名伪装格式 |
| 本机SQLite | 保留 | 用户明确选择资料目录，数据库保存确认事实、索引与元数据，原始材料可追溯 | 迁移保留旧数据；加密、备份和锁定方案需结合Desktop能力确定；默认离线可用 |
| Desktop原生Agent | 保留 | 选择材料和时间范围后准备任务快照，交给原生会话，回顾/归档结果 | 不复制聊天UI，不上传全部病历，不自动回写事实；患者资料切换时校验会话归属 |
| 安宁疗护/临终照护 | 一期不建专属模块，二期扩展 | 一期共用症状/生活记录和资料导出；二期增加舒适照护关注、患者表达的照护目标、联系与家庭沟通 | 不预测预后/死亡时间；不能用“一般症状记录”宣称已覆盖安宁疗护服务 |
| 去世后家属哀伤管理 | 二期新增 | 家属自主入口、访问/共享边界、纪念资料和经审核的哀伤支持资源 | 需患者生前授权或合法家属确认；不自动评估哀伤阶段/风险，不把家属数据并入患者病历 |

## 一期拒绝/延期清单

- 拒绝：胰腺癌特有字段、分类、用药方案、临床试验数据和既有诊疗建议映射。
- 拒绝：自动判断复发、铂敏感/耐药、预后、药物适用性、严重程度或治疗效果。
- 延期：多用户云端协作、医疗机构账户、家庭成员遗传风险图谱、自动从指南生成治疗路径、患者社区/社交网络。
- 条件延期：如临床试验快照无法证明来源授权、更新日期和地区适用性，则一期采用“可信来源链接+人工核实记录”，不发布无来源数据库。
