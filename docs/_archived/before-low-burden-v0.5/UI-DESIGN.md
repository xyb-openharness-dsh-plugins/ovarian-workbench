# 卵巢癌患者工作台 UI 设计方向 v0.2

状态：视觉方向已收到用户提供的参考，尚无高保真原型、实机预览或患者可用性确认。

## 用户与体验目标

女性中心、尊重、温暖、有韧性。让患者和家属在长期治疗、安宁疗护及哀伤支持等不同阶段都能找到清晰、平静、可依靠的入口。避免把女性气质简化为粉色、装饰或“积极战胜”叙事；不论治疗状态，界面保持尊严、选择权和可读性。

## 品牌参考

- **小巢宝社区 Logo：** 用户提供的 Image #2 已保存为 `assets/brand/xiaochao-community-logo.png`，来源/hash见 assets/manifest.json。保持原比例与留白，不改色、不裁切、不重绘。starter 中的 `xyb-logo.png` 实际为机器人，是另一素材；上一版把它当作小巢宝Logo的描述已纠正。用户已授权本项目设计参考；对外公开再分发范围尚未确定。
- **National Ovarian Cancer Coalition (NOCC)：** 用户提供 [About NOCC](https://ovarian.org/about-nocc/) 作为卵巢癌组织与支持服务参考。其网站导航覆盖患者、照护者、同伴支持、心理支持、营养/餐食与 grief and loss support，适合启发服务信息架构；它是美国组织，本项目不暗示双方合作、背书或将其服务直接提供给中国用户。
- 色彩参考取自用户提供的 NOCC 青绿色标识和小巢宝 Logo。以下色值仅为原型起点，非 NOCC 官方设计规范：

| 角色 | 初始色值 | 用法 |
| --- | --- | --- |
| 深青绿 | `#007F83` | 主操作、选中状态、重点标题 |
| 深墨绿 | `#075B60` | 正文强调、深色背景文字 |
| 柔和青绿 | `#82C9CC` | 插图、轻提示、次级标记 |
| 极浅青 | `#EAF7F6` | 轻量分区/卡片底色 |
| 暖白 | `#FCFBF8` | 主要页面背景 |
| 深灰 | `#243238` | 正文文字 |

颜色须按实际字号和状态检查 WCAG AA 对比度；浅青绿不直接用作小号文字。危险、警告、成功状态还需形状、图标和文字共同表达，不只依赖颜色。所有颜色落到 `.wb-root` 局部语义 token，不修改 Desktop 宿主全局样式。

## 界面语言与组件

- 用清楚、温和、无评判的中文；区分“患者记录”“报告内容”“医生记录”“待核对”“家属支持”。避免“失败”“放弃治疗”等归责词。
- 采用业务整页布局，保留 Desktop 原生会话与公共导航。顶部呈现当前患者资料目录状态和主要任务入口；让临床治疗、营养支持、心理支持三条照护主轴可被看见，并在安宁疗护/家属支持阶段继续提供入口。
- 卡片和时间轴以日期、来源、状态、下一步为主要信息；治疗记录与营养/心理/症状条目可按用户选择折叠，重要信息无需先读长篇科普。
- 使用圆角与轻量留白建立亲和感，阴影克制；图标选用简单线性造型。小巢宝 Logo 仅作品牌识别，不重复做大面积水印。
- 字体优先使用系统中文无衬线字体；支持大字和窄窗口。图表提供表格视图，保证色觉差异用户能分辨数据。
- 安宁疗护、临终照护与哀伤支持页面保持同一设计体系，避免用沉重黑灰视觉暗示死亡，也避免以鲜艳庆祝式表达消费哀伤；由患者/家属共同评审文案和呈现。

## 页面结构草案（按阶段）

### 一期：对齐小胰宝功能范围

八个一级入口统一为：看板、病情整理、病情一图秀、临床、营养支持、心理支持、全程管理、收藏与回顾；设置为公共入口。具体页面以 SPEC v0.4 和 CORE-MODULES 为准。

- 看板用近期任务和临床/营养/心理三条主轴摘要帮助进入任务，不堆满空指标。
- 病情整理：资料库、报告核对、病情档案、指标检测、病情汇总；支持源文与候选对照。
- 病情一图秀：独立多轨画布、指标卡、日期/轨道筛选和可回顾的画布快照；所有数据回源。
- 临床：治疗历程、临床档案、试验检索、资料对照、我的关注、来源；阴性/未检测等状态清晰可辨。
- 营养/心理各有记录、历史、可选讨论与摘要入口；心理私密内容默认不分享，不做打卡积分。
- 顶部资料目录/原生会话两种独立状态；business-first下Agent按需显示，不把0.65误当整页模式的固定占屏比例。

### 二期：安宁疗护与家属哀伤支持扩展

1. 安宁疗护：舒适照护记录、患者表达的照护目标、团队联系信息与沟通清单；不做预后推断。
2. 家属支持：照护者任务、家庭沟通资料、患者去世后由家属自主选择的纪念与哀伤支持资源；不自动推断或量化哀伤阶段。
3. 生命周期与授权：患者生前意愿、经核验的家庭访问和分享、资料导出/保留/删除。

页面树、名称、顺序和可见内容仍需患者/照护者及临床团队共创确认。

## 可访问性与待验证

设计交付前检查文字对比度、键盘焦点、触控目标、大字/缩放、减少动效、读屏名称和非颜色状态表达。制作可交互原型后，在 Desktop 真实容器预览，并邀请不同治疗阶段患者/照护者评审；当前这些检查均未执行。

## 已确认的AI与任务主线（2026-10-17）

提供有来源、结合个人资料的解释与可讨论选项，医疗处置由专业团队确定。优先打通治疗期间日常帮助→持续问题/变化→共同准备复诊；资料和问题复用。具体首页入口、首个触发及信息层级仍待场景讨论，不从这一决定直接推导新导航。
