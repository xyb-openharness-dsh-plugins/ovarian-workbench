# 用户核心场景与恢复路径 v0.2

场景用于设计与验收。E03/E04为本轮用户提供的具体患者处境，其余示例仍是设计假设；均不冒充正式访谈结果。一期S1–S5，S6使用一期通用记录并在二期扩展，S7为二期。入口/退出必须允许部分资料和未完成任务，不能要求用户先建完所有档案。

## S1 新确诊的情绪支持与下一步导航；兼容初诊/跨院材料整理

- **直接依据：** E04“确诊已经让人崩溃…接下来要做那些事儿，完全不知道”；资料整理不是唯一开始方式。细节提案见 [J1](PATIENT-JOURNEYS.md)。
- **需要：** 先被理解、降低信息量，知道眼前可选择的一两件事和如何与团队沟通；允许无资料、不想填表或暂时退出。
- **候选任务：** 温和回应→可跳过的单一帮助选择→区分已知/未知→通俗解释与一小步导航→自愿保留问题/事项。手头有报告可交给资料整理，无报告不阻止通用帮助。
- **产物：** 简短已知/未知、可选择的下一步/沟通问题；如愿导入，仍可形成可回源档案/摘要。未定的检查/治疗不变成系统必做清单。
- **恢复：** 可以只读、暂停或找已配置支持入口；家属参与需尊重本人意愿和分享范围。跨院就诊可继续使用R01–R04的材料整理完整流程。
- **验收关联：** G01/P01/A01/R01–R04；现有AC01–AC03/AC08/AC11/AC18；J1降负担条件待原型/验收细化。

## S2 治疗期间日常理解与照护→共同准备复诊（已确认优先主线）

- **直接依据：** E03描述多份血液/标志物/影像混着治疗、无力核对/问诊/思考下一步。当前主要负担不是缺记录功能。详细草稿/重点疑点提案见 [J2](PATIENT-JOURNEYS.md)，其信任规则待Q4回答。
- **触发/输入：** 患者或家属看不懂一份检查/治疗资料，或正为进食、症状、情绪困扰；可以只有一个问题和已有资料，不要求先完成整套建档。
- **日常任务：** 可直接交一批材料或只提一个问题，无需先组织清楚问诊问题→选择已有记录或导入材料→先整理可回源内容并集中少量关键疑点（草稿参与方式待Q4）→获得区分个人依据/知识来源的通俗解释→查看可讨论选项、需补信息和给专业团队的问题→自愿保留有用解释或讨论项。营养和心理私密内容按主体主动选择。
- **持续衔接：** 后续记录变化或专业团队回复，关联原问题；到复诊前直接复用同一批资料、治疗/指标/支持记录与问题，患者/家属共同选择范围→预览、编辑并导出复诊材料。不另建一份患者档案或要求重新描述全部困扰。
- **产物：** 来源明确的理解帮助、可讨论选项/问题清单、可更新的帮助记录及复诊摘要；处置由专业团队确定。
- **恢复：** 缺关键上下文先少量澄清；无可靠医学来源时只整理现有资料和问题，说明仍不能解释的部分；来源冲突并列。Agent不可用时保留问题草稿、原件和日历/记录操作。任何讨论选项不自动成为用药/饮食处方、确诊结果或治疗待办。
- **验收关联：** C01、M01–M03、O01–O03、N01/N02、P01、A01、G01/R04；AC04–AC08、AC11、AC13、AC14、AC18。

## S3 维持治疗或随访期间，回顾近期变化

- **触发/输入：** 用户希望看近几个月报告与药物变化，有些结果来自不同机构/单位。
- **任务：** 选择日期/指标→查看分组趋势与治疗节点→点开原始结果→记录医生文书里的药物更改→把问题加入摘要→保存一图秀快照或导出。
- **完成产物：** 来源和单位明确的趋势、当前时间窗下的一图秀、保留历史的治疗记录与摘要。
- **恢复：** 不可比序列分图；单次/缺日期结果保留点或表；源记录更正后历史快照显示过时提示；不生成复发判断。
- **验收关联：** M02/M03、O01–O03、C01、E01；AC04–AC06、AC11、AC15。

## S4 医生或患者希望了解某项临床研究

- **触发/输入：** 一个研究登记号或关键词；患者已有治疗、病理、IHC及分子报告，部分检测未知。
- **任务：** 试验检索/筛选→打开登记详情/来源→收藏→选择试验并看临床档案→把条款原文和相关资料并列→整理向中心核实的问题，必要时用Agent草拟→记录人工核实日期/回复。
- **完成产物：** 收藏的登记快照、资料对照问题单和来源；没有“匹配率/符合入组”结论。
- **恢复：** 无结果可改筛选或打开来源；数据未更新显示包日期；缺分子结果不等于阴性/不符合；试验状态改变保留关注历史。
- **验收关联：** C02–C06、G01、K01；AC07、AC09、AC10。

## S5 今天不舒服，患者或家属只想快速记一笔

- **触发/输入：** 治疗期间精力不足；只愿记录进食、一个症状、情绪或需要帮助的事项。
- **任务：** 从相应支持入口录入最少一项→选择记录主体和本人/代记→保存→在近期记录回顾→自行选择是否加入复诊问题或摘要。
- **完成产物：** 一条可编辑/删除的日期记录；可选的讨论事项。能量/蛋白质不必精算，漏记不记0，无打卡惩罚。
- **恢复：** 草稿恢复；私密心理记录默认不分享；代记不能标为患者本人填写；照护者自己的感受存到独立主体。不承担在线急症服务，联系医疗机构入口始终可找。
- **验收关联：** N01/N02、P01、A01、R04；AC08、AC11、AC14。

## S6 患者和家属需要讨论舒适、照护目标与联系安排

- **触发/输入：** 主动提出希望了解支持/姑息照护或安宁疗护，仍可能接受抗肿瘤治疗。
- **一期：** 沿用临床、症状、营养、心理和问题清单记录；可生成患者选择的沟通摘要，不自动设置“临终”阶段。
- **二期任务/产物：** 本人自愿记录在意事项、希望参加沟通的人、专业团队联系信息和讨论结果；愿望可更改并保留表达日期，不将普通笔记当成有法律效力的预先医疗指示。
- **恢复：** 可隐藏相关入口；未表达偏好显示未记录；专业文书与患者愿望有分歧时并列，不由系统决断。
- **验收关联：** H01；AC17（规划中）。

## S7 家属面对预期性哀伤或已经发生的丧失

- **触发/输入：** 家属主动进入支持资源页；患者去世前也可能需要相关支持。
- **二期基础任务：** 无需打开患者病历即可查看经维护的本地化资源→自愿保存个人记录/纪念→选择是否接收通知。
- **二期增强任务：** 若需要访问患者资料，另按患者生前意愿和实际授权范围办理；资源支持与病历权限不捆绑。
- **完成产物：** 家属独立支持空间与自愿求助记录；可关闭纪念/提醒，无固定哀伤阶段或恢复期限。
- **恢复：** 患者去世状态须人工明确确认并可纠错；先预览并暂停相关治疗/复查提醒，保留历史，不自动删除患者资料或把家庭其他成员的提醒一并停掉。
- **验收关联：** B01、B02；AC17（规划中）。
